# Brand kit: Pixel Chai

Saved by static-post-studio on 2026-11-18 (from the Vol. 4 speaker card). Kept next to the post, not in the
skill folder, because this was a test run. Copy to `static-post-studio/brands/pixel-chai.md` to make it the house kit.

## Identity
- What they do / for whom: a Bangalore design meetup series (volumes), for product/UX/visual designers
- Voice: playful, grown-up, warm. Never: cutesy, hype, emoji-as-decoration
- Handle / website / CTA preference: RSVP via link in bio (to confirm)
- Category codes kept: event info stack (what/when/where), one CTA. Broken: no stickers, no saturated zine colours

## Assets
- Logo: none supplied. Wordmark set in Fraunces 600, SOFT 100, 30 px
- Fonts: Fraunces (Google), Inter Tight (Google), JetBrains Mono (Google)
- Mandatory lines: none

## System
- Canvas: 1080×1350 (4:5); margin 88 px; furniture rows 72 px from the top and bottom; spacing unit 8 px
- Palette:
  - field · #3A2418 · decoction brown background, warm lamp glow top-left, grain
  - paper · #F3E4CC · milky chai, receipt/cards
  - ink · #2A1A10 · text on paper
  - muted · #6B5040 · labels on paper
  - accent · #A84718 · ginger: tick, status label, CTA line only
  - on-field · #F3E4CC / #C9AE90 · text on brown
- Type: Fraunces display (name 120, title 72), Inter Tight text 30, JetBrains Mono labels 26 caps +14%
- Emphasis device: italic switch in Fraunces (one word)
- Layout archetypes: receipt object on field (speaker/announcement); type statement on paper for quotes
- Motif: chai-stall receipt (perforation + punched notches, zig-zag tear, "Thank you · Visit again") + chai-glass ring
- Finish: grain on field, paper fibre on paper
- Furniture: wordmark top-left · "Vol. 0N · Bangalore" mono top-right · tagline bottom-left · CTA bottom-right

## Do / Don't
- Do: one receipt per post, details as mono rows, CTA as a status line ("Your seat: Pending")
- Don't: more than one accent, emoji on the artwork, drawn logos, big portraits that break the receipt
